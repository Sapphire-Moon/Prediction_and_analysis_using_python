#Supervised Learning on the Iris Dataset

This project demonstrates a beginner-friendly **supervised machine learning** workflow using the classic **Iris dataset**.  
It includes data exploration, visualization, model training, and evaluation.

---

## Project Structure
- `Supervised_Learning_Iris_Dataset_Polished.ipynb` → Jupyter notebook with step-by-step ML workflow
- `README.md` → Project description

---

## Steps in the Notebook
1. Load the Iris dataset  
2. Explore and visualize the data  
3. Train supervised learning models  
4. Evaluate model performance  
5. Draw conclusions and next steps
